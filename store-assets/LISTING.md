# Chrome 应用商店资料

## 基本信息

- 名称：X 专注阅读
- 主要语言：简体中文
- 分类：效率
- 单一用途：让用户手动收集 X 推文，并在屏蔽其他页面内容的界面中阅读所选推文及 X 原生评论。

## 简短说明

按住 Ctrl 拖动收集 X 推文，按 Ctrl+Shift+X 在专注界面中阅读所选内容和原生评论。数据仅保存在本机。

## 详细说明

X 专注阅读帮助你从信息流中挑出想认真看的推文，暂时避开其他内容。

• 按住 Ctrl 拖动推文，将它放到左侧出现的「＋」中。
• 按 Ctrl+Shift+X 打开毛玻璃专注界面，所选推文集中显示。
• 点击推文后，清单缩到左侧；右侧由 X 加载该推文的原生详情和评论，支持正常浏览回复。
• 可随时移除推文，或按 Esc 退出并回到原页面。

推文清单仅保存在 Chrome 本地扩展存储中。本扩展没有广告、分析服务或开发者服务器。仅在 x.com 和 twitter.com 上运行，不需要扩展专用账号。

本扩展是独立工具，与 X Corp. 无关联。

## 隐私与权限说明

- 隐私政策：https://gist.github.com/systems-biology-lirui/156b99c89937658cdc924a40643e81d4
- `storage`：在用户设备上保存其主动选择的推文链接、文字和排版快照。
- `x.com`、`twitter.com` 网站访问：识别用户按 Ctrl 拖动的推文，并在该网站上显示专注界面。
- 不出售或传输所收集的推文数据；不使用远程代码。

## 审核测试步骤

1. 打开 X 的推文列表或公开推文页面。
2. 按住 Ctrl，用鼠标左键拖动一条推文到它左侧出现的「＋」。
3. 按 Ctrl+Shift+X 进入专注模式。
4. 点击收集的推文，查看右侧 X 原生详情和回复；按 Esc 返回。
