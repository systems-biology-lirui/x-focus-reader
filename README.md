# X 专注阅读

在 X 页面收集想专心看的推文，并在一个毛玻璃覆盖的阅读模式里排除其他内容。

## 安装或更新

1. 在 Chrome 打开 `chrome://extensions`。
2. 开启「开发者模式」。
3. 首次安装时，点击「加载已解压的扩展程序」，选择本文件夹。
4. 如果已经安装上一版，点击此扩展卡片上的「重新加载」。
5. 刷新 X 页面。

## 使用

- **收集推文：**按住 Ctrl，从推文上开始拖动。开始拖动后，推文左侧出现「＋」。将鼠标移到「＋」并松开，即可加入专注阅读。
- **打开专注模式：**按 Ctrl+Shift+X，或点击 Chrome 工具栏中的扩展图标。再次按快捷键或按 Esc 退出。
- **阅读：**进入时，已收集的推文排在页面水平方向的中间。点击一条后，列表缩到左侧；X 会在当前标签页加载这条推文的原生详情和评论，显示在右侧。可以像普通 X 页面一样查看回复、展开对话并点击内容。
- **退出：**按 Esc、再次按 Ctrl+Shift+X，或点击「退出」。从详情页退出时会回到进入专注模式前的页面。
- **移除：**在专注模式中，把鼠标移到左侧推文上，点击右上角的 ×。

左侧清单使用 X 页面中的推文排版快照；右侧是 X 实时加载的原生页面，因此评论会随 X 更新。X 页面改版后，较早收集的快照可能与当前页面略有差异。上一版已保存的推文会继续显示；重新拖入同一条推文可以补上新版排版快照。数据保存在 Chrome 的本地扩展存储中，不会上传到服务器。
